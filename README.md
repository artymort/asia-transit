# Шаблон сайта автосалона

Одностраничная витрина продавца автомобилей на примере «DK AUTO».

## Что меняется для нового продавца

Название, контакты, адрес и весь каталог находятся в `dealer-config.js`. Верстку сайта для нового автосалона переделывать не требуется.

## Возможности

- каталог автомобилей в наличии;
- поиск и фильтры;
- быстрый просмотр с галереей и характеристиками;
- обращение по конкретному автомобилю;
- заявка на подбор машины под заказ;
- контакты, адрес и режим работы продавца;
- адаптивная версия для телефона и компьютера.

Сайт сделан на HTML, CSS и JavaScript без серверной части. Формы пока показывают локальное подтверждение и готовы к последующему подключению к CRM, Telegram или базе данных.
