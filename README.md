# АзияТранзит

Демонстрационный сайт сервиса подбора, проверки и доставки автомобилей из Китая и Южной Кореи в Россию.

В проекте есть:

- адаптивная главная страница;
- калькулятор таможенной пошлины и утилизационного сбора;
- автомобили в наличии с фильтрацией по стране;
- быстрый просмотр автомобиля с галереей и характеристиками;
- описание проверки, оформления и доставки.

Проект выполнен на HTML, CSS и JavaScript без серверной части.
