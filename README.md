# DK AUTO

Публичная витрина автомобилей и закрытое рабочее пространство сотрудников.

Опубликованная версия: <https://dk-auto-market.artemloko2002.workers.dev/>

## Возможности

- каталог автомобилей и отдельные страницы объявлений;
- личный кабинет сотрудника по адресу `/login`;
- создание, редактирование, публикация и архивирование автомобилей;
- публичные и внутренние характеристики;
- статистика просмотров за день, неделю и всё время;
- адаптивная версия для телефона и компьютера.

## Развёртывание

Рабочая версия размещается в Cloudflare Workers и использует D1. R2 и платный тариф не требуются: подготовленные изображения поставляются вместе со статическими файлами Worker.

```powershell
npm install
npm run check:cloudflare
npx wrangler d1 execute dk-auto-market --remote --file worker/schema.sql
npx wrangler d1 execute dk-auto-market --remote --file worker/seed.sql
npx wrangler deploy
```

Логин администратора задаётся переменной `ADMIN_LOGIN`, пароль хранится только в секрете Cloudflare `ADMIN_PASSWORD` и не добавляется в репозиторий.

Локальная Express-версия проекта по-прежнему запускается командами `npm install` и `npm start`.
